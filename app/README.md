# 🧭 ایجنت‌های زندگی

وب‌اپ شخصی برای مدیریت بخش‌های مختلف زندگی با تیمی از ایجنت‌های هوش مصنوعی.
ایجنت‌ها با **Claude Agent SDK** اجرا می‌شوند و در یک **نمودار درختی** نمایش داده می‌شوند.

## اجرا

```bash
cd app
npm install
npm start
```

بعد این آدرس را در مرورگر باز کنید: http://127.0.0.1:4567

**احراز هویت:** یکی از این دو لازم است:
- متغیر `ANTHROPIC_API_KEY` تنظیم شده باشد، یا
- Claude Code روی همین سیستم وارد حساب شده باشد.

## سه اصل طراحی

### ۱. نظم ذهنی
- **ثبت سریع ذهن:** بالای صفحه هر فکری را بنویسید؛ کار، ایده، نگرانی یا یادداشت. «ستاد زندگی» آن را دسته‌بندی می‌کند، برای ایجنت درست تسک روشن و قابل اقدام می‌سازد و اگر چیزی درباره‌ی شما بود، در «شناخت من» ثبت می‌کند. تسک‌هایی که ایجنت‌ها می‌سازند تا شما اجرا نکنید اجرا نمی‌شوند.
- **تخته‌ی کارها:** همه‌ی کارهای همه‌ی ایجنت‌ها در سه ستون «در انتظار / در حال اجرا / انجام شده» و در یک نگاه.
- **درخت:** ساختار ایجنت‌ها و گروه‌ها و وضعیت لحظه‌ای هر کدام.
- همه‌ی ایجنت‌ها دستور دارند جواب را مرتب، کوتاه و قابل اقدام بدهند و کار باز را رها نکنند.

### ۲. ذخیره‌ی همه‌ی داده‌ها (پایه‌ی «نسخه‌ی دیجیتال من»)
همه‌چیز در پوشه‌ی `data/` ذخیره می‌شود و هیچ‌چیز پاک نمی‌شود:

| فایل | محتوا |
|---|---|
| `data/history/journal.jsonl` | دفتر رویدادها: هر ثبت سریع، تسک، اجرا، نتیجه، تصمیم «اجازه/رد» شما، تغییر تنظیمات (با مقدار قبل و بعد)، بایگانی و بازگردانی |
| `data/history/tasks/<id>.jsonl` | گزارش کامل هر تسک، شامل همه‌ی پیام‌های خام ایجنت‌ها |
| `data/me.md` | «شناخت من»: ترجیحات، عادت‌ها، ارزش‌ها و تصمیم‌های شما که ایجنت‌ها یاد می‌گیرند و قبل از هر کار می‌خوانند |
| `data/agents.json` | ایجنت‌ها، گروه‌ها و تسک‌ها |

- ایجنت‌ها و تسک‌ها حذف نمی‌شوند، **بایگانی** می‌شوند و تاریخچه‌شان می‌ماند.
- در صفحه‌ی «شناخت من» دکمه‌ی **خروجی کامل** همه‌ی داده‌ها را در یک فایل JSON می‌دهد.
- پوشه‌ی `data/` در git نیست، چون شخصی است. از آن نسخه‌ی پشتیبان بگیرید، یا با `LIFE_DATA=/مسیر/پوشه npm start` آن را در یک پوشه‌ی همگام‌شده (مثلاً Google Drive) بگذارید.

### ۳. انعطاف: ایجنت و گروه
- **ایجنت:** با «+ ایجنت» بسازید، با «زیرمجموعه‌ی» جایش را در درخت عوض کنید، با «بایگانی» کنارش بگذارید و هر وقت خواستید برگردانید.
- **گروه:** با «+ گروه» از هر ایجنتی که بخواهید، از هر شاخه‌ی درخت، یک تیم بسازید. مثلاً «برنامه‌ریزی هفتگی» از سلامت، کار و مالی. گروه هماهنگ‌کننده‌ی خودش را دارد و کار را بین اعضا تقسیم می‌کند. در درخت، اعضای گروه نقطه‌چین نشان داده می‌شوند.
- **همکاری:** هر ایجنت می‌تواند کار را به زیرمجموعه‌هایش بسپارد و هر گروه به اعضایش. همه‌ی ایجنت‌ها یادداشت‌های مشترک (`workspace/shared/notes.md`) و «شناخت من» را می‌خوانند.

## تنظیمات هر ایجنت یا گروه
نام، آیکون، توضیح، دستورالعمل (system prompt)، مدل، جایگاه در درخت یا اعضای گروه، ابزارهای مجاز، سرورهای MCP و سطح دسترسی:

| سطح | رفتار |
|---|---|
| با تأیید من | خواندن آزاد است؛ برای هر کار دیگر یک کارت تأیید در صفحه نمایش داده می‌شود. |
| ویرایش خودکار | ساختن و ویرایش فایل‌ها خودکار است؛ بقیه‌ی کارها با تأیید شما. |
| دسترسی کامل | همه‌ی ابزارهای مجاز بدون پرسیدن اجرا می‌شوند. |

ابزارهای داخلی اپ (ثبت تسک، فهرست کارها، خواندن و ثبت «شناخت من») همیشه بدون پرسش در دسترس‌اند.

## اتصال به سرویس‌ها (MCP)

در تب «تنظیمات و دسترسی‌ها» هر ایجنت، سرورهای MCP را به‌صورت JSON وارد کنید. مثال:

```json
{
  "filesystem": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/me/Documents"]
  }
}
```

ابزارهای این سرورها در اختیار همین ایجنت قرار می‌گیرند، چه مستقیم تسک بگیرد و چه والدش کاری را به او بسپارد.

## مدیریت از طریق Claude

ایجنت‌های پیش‌فرض در `seed/agents.json` تعریف شده‌اند و اولین اجرا از روی آن `data/agents.json` را می‌سازد. از Claude Code بخواهید ایجنت یا گروه پیش‌فرض اضافه کند، دستورالعمل‌ها را تغییر دهد یا امکان تازه‌ای به اپ اضافه کند. اگر Claude Code را روی همان سیستمی اجرا کنید که اپ رویش است، می‌تواند `data/` را هم بخواند و تحلیل کند.

## فایل‌ها

| فایل | کار |
|---|---|
| `server.mjs` | سرور Express و اجرای ایجنت‌ها با `query()` از Agent SDK |
| `public/app.js` | ثبت سریع، نمودار درختی (D3)، تخته‌ی کارها، شناخت من، پنل تسک‌ها و تنظیمات، کارت‌های تأیید |
| `seed/agents.json` | ایجنت‌ها و گروه پیش‌فرض |
| `data/` | همه‌ی داده‌های شخصی و تاریخچه (در git ذخیره نمی‌شود) |
| `workspace/` | پوشه‌ی کاری مشترک ایجنت‌ها (در git ذخیره نمی‌شود) |

## نکته‌ی امنیتی

سرور فقط روی `127.0.0.1` اجرا می‌شود، چون ایجنت‌ها به فایل‌ها و ابزارها دسترسی دارند. اگر می‌خواهید از جای دیگری به آن دسترسی داشته باشید، اول یک لایه‌ی احراز هویت اضافه کنید و بعد `HOST` را تغییر دهید.
