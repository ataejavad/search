# 🧭 ایجنت‌های زندگی

وب‌اپ شخصی برای مدیریت بخش‌های مختلف زندگی با تیمی از ایجنت‌های هوش مصنوعی.
ایجنت‌ها با **Claude Agent SDK** اجرا می‌شوند و در یک **نمودار درختی** نمایش داده می‌شوند.

## اجرا

```bash
cd app
npm install
npm start
```

بعد این آدرس را در مرورگر باز کنید: http://127.0.0.1:4567

**احراز هویت:** یکی از این دو لازم است:
- متغیر `ANTHROPIC_API_KEY` تنظیم شده باشد، یا
- Claude Code روی همین سیستم وارد حساب شده باشد.

## چطور کار می‌کند

- **درخت ایجنت‌ها:** «ستاد زندگی» در ریشه است و ایجنت‌های بخش‌ها (مالی، سلامت، کار، یادگیری، خانه) زیرمجموعه‌ی آن هستند.
  - هر ایجنت می‌تواند زیرمجموعه‌ی خودش را داشته باشد. مثلاً «ایمیل و تقویم» زیرمجموعه‌ی «کار و شغل» است.
- **همکاری ایجنت‌ها:**
  - وقتی تسکی را به یک ایجنت می‌دهید، همه‌ی زیرمجموعه‌هایش به‌عنوان subagent در اختیارش قرار می‌گیرند و می‌تواند کار را به آن‌ها بسپارد.
  - ایجنتی که مشغول کار است، در نمودار با رنگ آبی مشخص می‌شود.
- **حافظه‌ی مشترک:**
  - همه‌ی ایجنت‌ها در پوشه‌ی `workspace/` کار می‌کنند.
  - فایل `workspace/shared/notes.md` حافظه‌ی مشترک آن‌هاست.
- **تنظیمات هر ایجنت:** نام، آیکون، توضیح، دستورالعمل (system prompt)، مدل، جایگاه در درخت، ابزارهای مجاز، سرورهای MCP و سطح دسترسی.
- **سطح دسترسی:**

  | سطح | رفتار |
  |---|---|
  | با تأیید من | خواندن آزاد است؛ برای هر کار دیگر یک کارت تأیید در صفحه نمایش داده می‌شود. |
  | ویرایش خودکار | ساختن و ویرایش فایل‌ها خودکار است؛ بقیه‌ی کارها با تأیید شما. |
  | دسترسی کامل | همه‌ی ابزارهای مجاز بدون پرسیدن اجرا می‌شوند. |

- **تسک‌ها:**
  - هر تسک گزارش زنده‌ی کارهای ایجنت، نتیجه‌ی نهایی و هزینه‌ی تقریبی را نشان می‌دهد.
  - بعد از پایان یک تسک می‌توانید درباره‌ی همان تسک با ایجنت ادامه دهید (همان جلسه ادامه پیدا می‌کند).

## اتصال به سرویس‌ها (MCP)

در تب «تنظیمات و دسترسی‌ها» هر ایجنت، سرورهای MCP را به‌صورت JSON وارد کنید. مثال:

```json
{
  "filesystem": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/me/Documents"]
  }
}
```

ابزارهای این سرورها در اختیار همین ایجنت قرار می‌گیرند، چه مستقیم تسک بگیرد و چه والدش کاری را به او بسپارد.

## مدیریت از طریق Claude

همه‌ی ایجنت‌ها و تسک‌ها در فایل `data/agents.json` ذخیره می‌شوند. برای همین می‌توانید از Claude Code بخواهید ایجنت جدیدی بسازد، دستورالعمل‌ها را تغییر دهد یا امکان تازه‌ای به اپ اضافه کند.

## فایل‌ها

| فایل | کار |
|---|---|
| `server.mjs` | سرور Express و اجرای ایجنت‌ها با `query()` از Agent SDK |
| `public/app.js` | نمودار درختی (D3)، پنل تسک‌ها و تنظیمات، کارت‌های تأیید |
| `data/agents.json` | تعریف ایجنت‌ها و تسک‌ها |
| `workspace/` | پوشه‌ی کاری و حافظه‌ی مشترک ایجنت‌ها (در git ذخیره نمی‌شود) |

## نکته‌ی امنیتی

سرور فقط روی `127.0.0.1` اجرا می‌شود، چون ایجنت‌ها به فایل‌ها و ابزارها دسترسی دارند. اگر می‌خواهید از جای دیگری به آن دسترسی داشته باشید، اول یک لایه‌ی احراز هویت اضافه کنید و بعد `HOST` را تغییر دهید.
